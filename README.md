# Брюс Ли 3.0

Приложение с программой тренировок на 20 недель (140 дней, график 2/2): каждый день, подбор веса по RPE, таймеры отдыха и интервалов, утренний ритуал, техника упражнений. Сигнал в конце отдыха приходит уведомлением, и Huawei Health пересылает его на часы.

## Установка на телефон

1. Открой на телефоне раздел **[Releases](../../releases/latest)** и скачай файл `BruceLee3-….apk`.
2. Открой скачанный файл. Если телефон спросит, разреши установку из этого источника (браузера или «Файлов»).
3. При первом запуске разреши уведомления.

Новая версия ставится поверх старой, записи сохраняются.

## Сигнал на часы Huawei GT 5

1. В приложении: **Профиль → Проверить сигнал**.
2. В Huawei Health: **Устройства → часы → Уведомления** — включи и отметь «Брюс Ли 3.0».
3. На Realme: **Настройки → Приложения → Брюс Ли 3.0 → Батарея** — разреши работу в фоне и автозапуск.

## Как устроено

- `tools/` — генератор плана (`gen.py`, `ex.py`) и машинной разметки подходов и таймеров (`spec.py`).
- `web/app.html` — само приложение (HTML + JS), `tools/build.py` собирает его в `app/src/main/assets/index.html`.
- `app/` — Android-обёртка: WebView, уведомления через AlarmManager, экран не гаснет, резервная копия в «Загрузки».
- `.github/workflows/build.yml` — GitHub собирает подписанный APK и публикует его в Releases при каждом изменении.
