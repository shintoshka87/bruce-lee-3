# Брюс Ли 4.0

Приложение с программой тренировок на 180 дней по книге «Брюс Ли: Искусство выражения человеческого тела», под график 2/2 (две смены, два выходных). Только физическая подготовка, без бойцовской техники. Силовая — 1 раз за цикл (около 2 раз в неделю), в каждой — оба главных движения; выносливость — каждый день (Зона 2, лёгкий велотренажёр, бег с ускорениями); раунды Ли каждый цикл: скакалка, бой с тенью и груша как интервальная нагрузка плюс общефизическая программа Ли — отжимания, приседания «на четыре счёта», прыжки. В Фазах 2–3 — броски медбола для мощности корпуса, в Фазе 3 питание на поддержании. Перед стартом — Цикл 0 со стартовыми замерами, контрольные тесты в Дни 57–60, 117–120 и 177–180.

В приложении: план на каждый день, вес подставлен из плана и пересчитывается по запасу повторов, таймеры отдыха и интервалов, техника каждого упражнения со страницей книги, графики силы и таблица тестов. Сигнал в конце отдыха приходит уведомлением, и Huawei Health пересылает его на часы.

## Установка на телефон

1. Открой на телефоне раздел **[Releases](../../releases/latest)** и скачай файл `BruceLee-4.0.….apk`.
2. Открой скачанный файл. Если телефон спросит, разреши установку из этого источника (браузера или «Файлов»).
3. При первом запуске разреши уведомления.

Версия 4.0 ставится поверх 3.0: профиль, вес тела и настройки переносятся. Тренировки версии 3 в новый план не попадают, но остаются в телефоне — их можно сохранить файлом: **Профиль → Сохранить записи версии 3**.

## Сигнал на часы Huawei GT 5

1. В приложении: **Профиль → Проверить сигнал**.
2. В Huawei Health: **Устройства → часы → Уведомления** — включи и отметь «Брюс Ли 4.0».
3. На Realme: **Настройки → Приложения → Брюс Ли 4.0 → Батарея** — разреши работу в фоне и автозапуск.

## Как устроено

- `tools/plan.py` — логика программы: 180 дней, циклы, протоколы рабочих дней, силовые дни, бой, тесты и ворота.
- `tools/exercises.py` — справочник упражнений: техника, частые ошибки, замены, страница книги.
- `tools/appdata.py` — собирает из них данные приложения; `tools/build.py` вставляет их в `web/app.html` и пишет `app/src/main/assets/index.html`.
- `web/app.html` — само приложение (HTML + JS).
- `app/` — Android-обёртка: WebView, уведомления через AlarmManager, экран не гаснет, резервная копия в «Загрузки».
- `.github/workflows/build.yml` — GitHub собирает подписанный APK и публикует его в Releases при каждом изменении в `main`.

После правок в `tools/` или `web/` запусти `python3 tools/build.py` (Python 3, без сторонних пакетов) и закоммить обновлённый `app/src/main/assets/index.html`.
