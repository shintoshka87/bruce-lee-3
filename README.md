# Брюс Ли 5.0 — «Позвоночник прежде всего»

Приложение с программой тренировок на 20 недель (140 дней, 35 циклов) под график 2/2: две смены по 12 часов и два выходных. Программа построена вокруг поясничной грыжи, протрузий и гиперлордоза: никакой нагрузки на позвоночник сверху вниз — без приседаний и становой со штангой, жимов стоя, тяг в наклоне, прыжков, скакалки и бега.

- **Смена 1** — дома 23–28 минут: положение таза, кор (Большая тройка Макгилла), дыхание.
- **Смена 2** — дома 25–30 минут: зона 2 на велотренажёре и разгрузка спины.
- **Выходной 1** — зал А, 65–90 минут: жимы на тренажёрах, тяги с упором, hip thrust, статодинамика, зона 2.
- **Выходной 2** — зал Б, 55–90 минут: всё тело без осевой нагрузки, интервалы, мешок (только прямые удары), гибкость.

Волны зала: Л (лёгкая), С (средняя), Т (тяжёлая), Р (разгрузка). Блоки по 6 циклов: Комплексы №1 и №2 чередуются, уровень нагрузки растёт каждые два блока. Перед стартом — Цикл 0 (допуск врача, замеры, контрольные веса), тесты в дни 71 и 139.

В приложении: план на каждый день; вес подставляется по прошлой записи и пересчитывается под волну дня; утренний светофор (в жёлтый день веса −15%); пульсовые зоны по пульсу покоя из профиля; таймеры отдыха, интервалов и удержаний; техника каждого упражнения с заменой; графики силы, веса и талии; таблица тестов. Сигнал в конце отдыха приходит уведомлением, и Huawei Health пересылает его на часы.

## Установка на телефон

1. Скачай файл `BruceLee-5.0.….apk` на телефон.
2. Открой его. Если телефон спросит, разреши установку из этого источника.
3. При первом запуске разреши уведомления.

Версия 5.0 ставится поверх 4.0: профиль, вес тела и журнал веса переносятся. Тренировки версии 4 в новый план не попадают, но остаются в телефоне — их можно сохранить файлом: **Профиль → Резервная копия → Сохранить записи версии 4**. Дату Дня 1 новой программы укажи в профиле.

## Как устроено

- `tools/plan.py` — логика программы: 35 циклов, волны, уровни, все прогрессии, тесты, светофор, питание.
- `tools/exercises.py` — справочник упражнений: техника, частая ошибка, замена, метка светофора.
- `tools/appdata.py` — собирает из них данные приложения; `tools/build.py` вставляет их в `web/app.html` и пишет `app/src/main/assets/index.html`.
- `tools/docgen.py` — таблицы для документа с планом из того же `plan.py`.
- `web/app.html` — само приложение (HTML + JS).
- `app/` — Android-обёртка: WebView, уведомления через AlarmManager, экран не гаснет, резервная копия в «Загрузки».
- `.github/workflows/build.yml` — GitHub собирает подписанный APK и публикует его в Releases при каждом изменении в `main`.

После правок в `tools/` или `web/` запусти `python3 tools/build.py` (Python 3, без сторонних пакетов) и закоммить обновлённый `app/src/main/assets/index.html`.
